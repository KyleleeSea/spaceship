How it works
  • Peer-to-peer. The two browsers talk directly over WebRTC. No game server: a tiny signaling service only brokers the connection.
  • Lockstep determinism. Both machines run the identical simulation and only exchange orders. Every turn is hashed and compared, so any divergence is detected.
  • Pause to re-plan. Each commander gets a limited number of pauses. While paused, both sides can rewrite orders; the pauser decides when to resume.
  • Rebalance. The host can set per-player budgets, pause counts, time limit, and a loser bonus that grows the losing fleet each rematch.
